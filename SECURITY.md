# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions of **Guardrail API**:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security of **Guardrail API** and its users is taken very seriously. If you discover a security vulnerability or security-related issue in this project, please follow these guidelines:

1. **Do not create a public issue** on GitHub.
2. Submit a private vulnerability report via [GitHub Security Advisories](https://github.com/CodeJairo/guardrail-api/security/advisories/new) on the repository.
3. If GitHub Advisories are not accessible to you, send an email to `codejairo@gmail.com` with:
   - A detailed description of the vulnerability.
   - Steps or proof-of-concept (PoC) to reproduce the issue.
   - Any suggested remediations or mitigations.

### Response Timeline
- **Initial Response:** Within 48 hours of receipt.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Advisory Release:** Coordinated release once patched and verified.

Thank you for responsibly disclosing security issues and helping keep the open-source community secure!
